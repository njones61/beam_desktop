# Beam Designer

Beam Designer is a Python desktop app for analyzing simply supported and
cantilever steel beams. It shows shear, moment, and deflection diagrams,
performs allowable stress and deflection checks, and can save designs and
export CSV results and PDF calculation sheets. It is an educational tool,
not for design of record.

Install Python with Tkinter, then install ReportLab for PDF export:

```bash
python -m pip install -r requirements.txt
```

Start the app from this folder:

```bash
python beam_designer.py
```
